# Victor Samuel Ekpenyong: Student Portfolio & Academic Planner

COS 106 (Introduction to Web Technologies) term project, Miva Open University.

A responsive multi-page website built with HTML, CSS and JavaScript.

## Pages
- `index.html`: Home (photo, welcome, bio, navigation)
- `about.html`: Education, career goals, skills table, hobbies, intro video
- `projects.html`: Four projects with descriptions, screenshots and links
- `planner.html`: Academic planner (add, complete, delete tasks; saved in the browser)
- `contact.html`: Contact form with JavaScript validation

## Features
- Dark theme by default, with a button to switch to a light theme in Miva colours
- Responsive layout (Flexbox and CSS Grid) with a mobile menu
- Transitions and animations (typing effect, hover effects, scroll reveal)
- Form validation: no empty fields, valid email format, digits-only phone number

## Run locally
Open `index.html` in a browser. No build step is needed.

## Deploy
Hosted with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/root`).
